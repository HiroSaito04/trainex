TRAINEX — PNR Vigilance Timing Revision

REFERENCE: user-provided PNR Train Sets – Technical Specifications excerpt.

INSTALL FULL PROJECT:
1. Back up your existing TRAINEX repository and uncommitted changes.
2. Extract TRAINEX_PNR_Vigilance_Complete.zip; the source is inside trainex/.
3. Replace or merge the necessary source files into your checked-out repo.
4. From the repo root, npm install; then npm run dev for local testing.
5. In Arduino IDE, open hardware/esp32/firmware/TrainexConsole/TrainexConsole.ino.
   Copy Secrets.example.h to Secrets.h before compiling. Use correct board/libs.
6. Test the online pairing and real ESP32 hardware separately; neither was
   verified or deployed automatically.

INSTALL HARDWARE-ONLY PATCH:
1. Back up and replace hardware/esp32/ with the hardware folder included here.
2. This patch alone does NOT implement the PNR simulation countdown; to get
   that timing use the complete project revision as well.
3. Verify your piezo rating before connecting GPIO32.

VIGILANCE: >=10 km/h; visual at 30s; buzzer at 32.5s; EB penalty at 35s.
Resets upon actual master detent movement or Vigilance ACK. No physical LEDs.
Master handle EB remains active; separate push button is EB Reset.

Refer to PNR_VIGILANCE_REVISION.md for full implementation notes.
